# QuPath

## What is QuPath?

[QuPath](https://qupath.github.io/) is an open-source and free software for bioimage
analysis. The software was originally written to analyze pathology images, but has since
been used for fluorescence and electron microscopy images.

We recommend QuPath as a modern replacement for Fiji/ImageJ.
